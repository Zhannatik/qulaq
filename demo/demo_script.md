# Демо Qulaq: тестовый чат и сценарий видео на 3 минуты

Всё вымышленное: никаких настоящих детей, учителей и школ.

## 1. Как собрать тестовый чат (около 15 минут)

1. В WhatsApp создайте группу из двух человек (вы и Канат), назовите «3А класс (демо)».
   Тогда в экспорте будет два отправителя: «Учитель» (вы) и «Родитель» (Канат). Переименуйте
   себя в контактах на «Учитель», а Каната на «Родитель», чтобы имена в чате были такими.
2. Отправляйте сообщения **в этом порядке, в один вечер** (лучше сегодня или завтра).
   Голосовые читайте **своими словами и естественно**, как настоящая учительница: важны только
   факты из колонки «Что должно быть в дайджесте». Не читайте слишком чисто.
3. После этого: группа → ⋮ → Ещё → Экспорт чата → С медиафайлами, и пришлите zip мне.
   Zip не распаковывайте и не меняйте.

Запишите и один **«трудный» голосовой**, как есть, без подготовки: на ходу, с шумом (на кухне,
в коридоре), быстро говоря числа. Это нужно для честной демонстрации ⚠️: мы не подстраиваем
результат, а показываем, что программа делает, когда не уверена.

## 2. Как проверить результат (для вас, не для видео)

Дата «сегодня» для запуска: день отправки сообщений плюс один (вечерний дайджест).

```
python scripts/run_digest.py "C:\Users\User\Downloads\demo_chat.zip" --days 3 --now 2026-10-28 --out demo_digest.md --save-transcripts demo_transcripts.json
```

Сравните с колонкой «Что должно быть в дайджесте». Сохраните все расхождения: они пойдут в раздел
«Что мы нашли» в README. Ничего не правьте руками.

## 3. Сценарий видео ровно на 3 минуты

Правила: показываем только то, что сделано за хакатон. Модели только Meta (Muse Voice Transcribe и Muse Spark).
Экран записывайте целиком, голос за кадром на английском (жюри международное), короткие фразы.

| Время | Что на экране | Что говорить |
|-------|---------------|--------------|
| 0:00–0:20 | Слайд или заставка: скриншот школьного чата в WhatsApp (вымышленный) с десятками голосовых | «In Kazakhstan, schools run on WhatsApp groups, and teachers send voice notes. Busy parents miss them: the concert, the money, the dress code.» |
| 0:20–0:50 | Экспорт чата в WhatsApp, затем команда `run_digest.py` в терминале | «Qulaq reads a normal WhatsApp export. It transcribes voice notes in Kazakh, Russian and mixed speech with Meta's Muse Voice Transcribe, and extracts events with Muse Spark.» |
| 0:50–1:30 | Готовый дайджест: «Срочно», «Не пропустите» | «Parents get one evening report: what, when, how much. Importance is decided by plain code rules, the model only extracts facts.» |
| 1:30–2:00 | Пункт с ⚠️ и цитатой «Из записи» | «Speech recognition can mishear five hundred as three hundred. So every voice note is read three ways, and any disagreement is flagged with the original words. Qulaq never presents a doubtful amount as fact.» |
| 2:00–2:40 | Claude Desktop: «Add confirmed events to my calendar and check conflicts» → .ics, конфликт 18:00 / 18:30 | «Through MCP, an assistant can act: export a calendar file with reminders and find the clash between the parents' meeting and the class photo. Doubtful items stay out until a parent confirms.» |
| 2:40–3:00 | Репозиторий, итог | «Built in a week for real families. Open source. No scraping of WhatsApp, only exports and forwarding.» |

Репетируйте с таймером: ровно 3:00, ни секундой больше.
